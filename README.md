# DocuVerse Studio

Premium Offline-First Desktop Document Workspace.

## Technology Stack

- React
- TypeScript
- Tauri
- Rust
- SQLite
- Python Workers

## Project Structure

- apps/desktop: Desktop application
- crates: Rust backend libraries
- workers/python: Python processing workers
- packages: Shared frontend packages
- modules: Optional application modules
- resources: Bundled resources
- docs: Project documentation
- tests: Testing infrastructure
