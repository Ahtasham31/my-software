# Brand Identity — DocuVerse Studio

## Name
DocuVerse Studio — conveys a universe of documents unified in one premium workspace.

## Logo
- Mark: rounded square with a folded document glyph and gradient (primary→accent).
- Wordmark: "DocuVerse" semibold + "STUDIO" tracking-wide, uppercase.
- Compact mark: icon only, used in collapsed sidebar.

## Color Usage
- Primary drives core actions and active state.
- Accent marks secondary emphasis (highlights, badges).
- Semantic colors (success/warning/error/information) are strictly semantic.

## Typography
- Sans for UI, Urdu fallback via `Noto Nastaliq Urdu`, mono for technical text.
- Title scale: display / title / section / card-heading.

## Tone
Professional, precise, calm. Avoid playful animation, gimmicky micro-copy.

## Do not copy
Do not imitate Adobe, Canva, Microsoft Office, CorelDRAW, or other commercial
product interfaces or brand marks.
